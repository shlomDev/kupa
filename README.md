# Kupa — everyday grocery shopping

Hebrew-first grocery browser with English and light/dark toggles.

Choose a store → enter a city or discover it from browser location → choose a branch. Only branches in that city are returned. Selecting a branch automatically fetches its product prices; the On sale tab fetches promotions for the same branch. There are no file imports, pasted JSON, source logs, Telegram credentials or technical setup in the shopping UI.

Products and offers support category sections, category/search/sort filters, favorites, grid cards and compact list views. Titles, brands, package quantities and unit prices use published fields. Categories inferred from titles are marked in product details. Photos load automatically using exact barcode matching from verified SuperPharm product photography, then Open Food Facts / Open Beauty Facts. Nested image fields in source JSON are preserved. Negative browser photo caches expire after one hour; missing images and quantities are never fabricated. Promotion amounts preserve quantity and eligibility conditions and are not converted into assumed per-item prices.

## Run locally

Requires Node.js 20+; no dependencies to install.

```sh
npm run build
npm run dev -- --port 3000
```

```sh
node tests/refresh.mjs
node tests/images.mjs
node tests/catalog.mjs
node tests/branches.mjs
node tests/source-response.mjs
node tests/feed-session.mjs
```

## Sources and limitations

Official branch directories are cached from SuperPharm, Rami Levi and Osher Ad. City names resolve from the government settlement directory. PriceFull and PromoFull feeds support gzip, JSON, UTF-8 XML and UTF-16 XML. Rami Levi and Osher Ad use the publicly published chain login sessions. SuperPharm can require browser verification on its price portal; the app reports this without displaying an unrelated branch catalog. GPS requires browser permission and a working city lookup. Exact barcode photo providers do not cover every product. Category sections use incremental rendering (48 more items per click).

The Worker is generated by scripts/build.mjs from src/, worker/backend.js, worker/feeds.mjs and data/. The existing hosting identity is preserved in .openai/hosting.json.

## Automatic refresh

The selected branch fetches both latest PriceFull and PromoFull immediately, then checks both every 30 minutes while the page is open. Returning to a suspended tab checks overdue feeds; reconnection forces a retry. A failed source keeps the previous successful catalog visible and does not prevent the other feed from refreshing. The displayed last-check time is specific to the active Prices or On sale tab. This browser refresh does not run when the app is closed; no unattended background schedule has been installed.
